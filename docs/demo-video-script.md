- デモは1台のサーバー（`pnpm build` → `pnpm --filter @moda/web start`）で動かす（[backlog.md の S-03](backlog.md)）。撮る前に一度サーバーを立ち上げ直し、記録をまっさらにする

## 作り方（Claude が行う）

1. `apps/web/.env.local` に本物の AI のキー（`ANTHROPIC_API_KEY`）を入れる（依頼主。コミットしない）
2. サーバーを立ち上げ直す（記録をまっさらにする）：`pnpm build` → `pnpm --filter @moda/web start -p 3100`
3. `video` で `node record-demo.mjs main`・`contra`・`emergency`（自動で録画。`out/demo/`）
4. `node compose.mjs` → `out/final.mp4`（冒頭・実演・締めをつなぎ、実演に BGM とナレーションを重ねる）

## 時間が足りないとき・機能ができていないとき

- **流れ5〜8 のどれかができていない**：その場面を撮らず、残った場面に秒数を回す。「予定」の機能を、動いているように見せる画像やアニメーションで代わりに見せない（規約）。必要なら結びの前に「今後：〇〇」と文字だけの画面を1枚出す
- **写真（2'）ができていない**：流れ2は名前の入力だけにする
- **3分を超える**：導入アニメーションをさらに短くする → 流れ1の英語への切り替えを省く → 流れ4の Wi-Fi を切る場面を省く、の順に削る。流れ4（緊急）と流れ5の禁忌で止まる場面は残す
- **時間が余る**：上の表の「時間が余れば」の場面（運転の警告・濫用防止の数量確認・店にない商品）を、流れ5に5秒ずつ足す
