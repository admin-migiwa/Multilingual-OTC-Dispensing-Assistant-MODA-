## 架空であることの約束

- 商品名はすべて「**モダ**」で始め、末尾に「（架空）」を付けます。製造販売元は「架空製薬」です。
- 成分は「**架空成分**＋記号（例：N1）」とし、どんな種類の成分かを括弧で添えます（例：解熱鎮痛・NSAID系）。
- 実在の商品名・会社名・添付文書へのリンクは書きません。区分と手順の組み合わせは、手元の参考資料（公開しない）にならっています。
- バーコード（JAN コード）と添付文書 PDF は持ちません（No.30・No.35）。
