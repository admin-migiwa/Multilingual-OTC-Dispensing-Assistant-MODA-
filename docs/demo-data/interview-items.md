# 問診の項目（ハッカソン版）

最終更新：2026-11-06（問診の流れを「ほしい薬がある」と「症状から探す」に分けた）
状態：**薬剤師確認済み（11/4・デモ用）。11/6 に問診の流れを2つに分けた（薬剤師である依頼主の判断）**（決まったこと No.31）

架空の薬（[drugs.md](drugs.md)）の禁忌判定に必要な項目だけです。次に聞く項目はサーバーが決め、1回に1項目だけ聞きます（CLAUDE.md 絶対に守るルール3）。

## 対象の患者さん

訪日外国人（旅行者）と在日外国人（日本に住んでいる方）の両方を想定します（11/4 薬剤師の判断）。在日の方は日本の病院に通っていることがあるため、処方薬（Q09）を聞き、お薬手帳があれば見せてもらいます（お薬手帳の写真は保存しない。決まったこと No.26）。

## 聞く順番の考え方（11/6 薬剤師の判断で、2つの流れに分けた）

ほしい薬が決まっている人は、早く買いたい・手間を省きたいことが多いので、その薬に関係のない質問はしない。

| 順 | ほしい薬がある | 症状から探す |
| --- | --- | --- |
| 1 | 言語を選ぶ | 言語を選ぶ |
| 2 | **年齢・性別**（Q01・Q02） | **年齢・性別**（Q01・Q02） |
| 3 | 薬を探して選ぶ | 症状を入力する（緊急キーワードを確かめる） |
| 4 | **選んだ薬の禁忌判定に使う項目だけ**を聞く（基本の項目 Q03〜Q10 のうち必要なものと、薬ごとの項目 Q11〜Q14・R01〜R04）。**いま飲んでいる薬（Q09）はどの薬でも聞く** | **基本の項目（Q03〜Q10）をすべて**聞く |
| 5 | 薬剤師の確認 | 薬剤師が候補の薬を選ぶ → その薬の薬ごとの項目を聞く |

- 「選んだ薬の禁忌判定に使う項目」は、[drugs.md](drugs.md) の各薬の「してはいけないことと注意」の行から決まる（プログラムでは禁忌判定のデータから自動で決め、問診が終わったのに判定に必要な答えが足りない、ということが起きないようにしている）
- 体重（Q05）は用量の確認に使うので、どちらの流れでも15歳未満には聞く。「ほしい薬がある」流れでは、15歳未満の体重は薬を選ぶ前に聞く（11/6 薬剤師の判断）
- いま飲んでいる薬（Q09）は、選んだ薬の判定に使わなくても、「ほしい薬がある」流れでも必ず聞く（薬を選んだあとに聞く）。在日の方の処方薬を薬剤師が見て、飲み合わせを判断するため。処方薬は判定には使わない（[contraindication-tests.md](contraindication-tests.md) の K39。11/6 薬剤師の判断）
- 下の一覧の「聞く条件」の「全員」は、「症状から探す」流れのときの条件。「ほしい薬がある」流れでは、選んだ薬の判定に使う項目だけを、その条件で聞く
- どの段階でも、緊急症状が出たら問診を止める（[emergency.md](emergency.md)）

「必要な項目がそろうまで問診を終えない」は、選ばれた薬すべての判定に使う項目が「確認済み」になった時点で満たすものとします。

## 「わからない」「かもしれない」と答えたとき（11/4 薬剤師の判断）

- その項目が禁忌に当たる薬は、判定を**禁忌**にする（可能性がある・わからない人には販売を避ける。推測で「問題なし」にしない）。
- 例外：Q08（薬のアレルギー歴）の「わからない」は「アレルギー歴なし」として扱う（11/5 薬剤師の判断。わからないなら成分を特定しようがないため）。
- 禁忌なので既定では選べない。薬剤師が PIN の再認証と理由の記録で解除することはできる（CLAUDE.md 絶対に守るルール4）。
- あわせて、その項目が禁忌にならない薬を**できるだけ候補として探し**、薬剤師の画面で先に並べる（例：ぜんそく歴が「わからない」なら、解熱鎮痛成分を含まない漢方 J を先に出す）。
- 最終的にどの薬にするかは薬剤師が決める。

## 聞かない・聞き直すときの決まり（design.md 7節から）

- 男性には妊娠・授乳を聞かない（サーバー側で除外する）。
- 一度に複数のことを答えたら、当てはまる項目をすべて確認済みにする。
- 意味の通らない答えには、推測で進めず、同じ質問をもう一度する。
- 「間違えました」には訂正を受け付ける。直前の答えをやり直すボタンも置く。
