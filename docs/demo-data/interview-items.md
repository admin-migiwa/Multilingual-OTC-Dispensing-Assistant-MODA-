# 問診の項目（ハッカソン版）

最終更新：2026-11-04
状態：**下書き・薬剤師の確認待ち**（決まったこと No.31）

架空の薬（[drugs.md](drugs.md)）の禁忌判定に必要な項目だけです。次に聞く項目はサーバーが決め、1回に1項目だけ聞きます（CLAUDE.md 絶対に守るルール3）。

## 聞く順番の考え方

1. **基本の項目**（全員）：言語選択のあと、どの薬でも必要なもの
2. **薬ごとの項目**：希望の薬、または候補の薬が決まってから、その薬の判定に必要なものだけを聞く
3. どの段階でも、緊急症状が出たら問診を止める（[emergency.md](emergency.md)）

「必要な項目がそろうまで問診を終えない」は、選ばれた薬すべての判定に使う項目が「確認済み」になった時点で満たすものとします。

## 聞かない・聞き直すときの決まり（design.md 7節から）

- 男性には妊娠・授乳を聞かない（サーバー側で除外する）。
- 一度に複数のことを答えたら、当てはまる項目をすべて確認済みにする。
- 意味の通らない答えには、推測で進めず、同じ質問をもう一度する。
- 「間違えました」には訂正を受け付ける。直前の答えをやり直すボタンも置く。
