## 1. 区分ごとに、承認の前に必要な手順

選んだ薬が複数あるときは、すべての区分の手順を合わせた一覧にします。1つでも未完了があれば承認できません。

| ID | 区分 | 承認できる人 | 承認の前に必要な手順 | 確認 | メモ |
| --- | --- | --- | --- | --- | --- |
| P01 | 要指導医薬品 | 薬剤師 | ①書面での情報提供（翻訳版の説明書＋原文）②理解の確認 ③法定項目の記録 | ☑ | ②③は承認の後、会計案内の前に行う（No.25。11/4 薬剤師が了承） |
| P02 | 第1類医薬品 | 薬剤師 | 要指導医薬品と同じ | ☑ | |
| P03 | 特定要指導医薬品 | 薬剤師 | 要指導医薬品の手順に加えて ④別紙書類の確認 ⑤薬剤師の前での服用の確認 | ☑ | 事前の電話など販売の条件は**未確認・あとで追加**（参考資料の確認待ち） |
| P04 | 指定濫用防止医薬品 | 薬剤師 | 年齢・購入数量（大容量・複数個）・他店での購入状況・複数購入の理由・使用目的の確認、濫用の危険についての書面での情報提供、18歳未満は別紙で氏名を確認し別紙番号を入力 | ☑ | 下の「数量基準」とあわせて使う |
| P05 | 指定第2類医薬品 | 薬剤師 | 禁忌の確認と、相談を促す表示 | ☑ | ハッカソン版は登録販売者の承認を扱わない |
| P06 | 第2類医薬品 | 薬剤師 | 禁忌の確認 | ☑ | |
| P07 | 第3類医薬品 | 薬剤師 | 禁忌の確認 | ☑ | |

> **承認と手順の順番について（11/4 薬剤師が了承）**：決まったこと No.25 で「承認と同時に販売記録を作り、理解の確認の結果はあとで版を足して記録する」と決めました。上の「理解の確認」「法定項目の記録」は、承認を止める条件ではなく、**会計案内に進む前に終わっていなければならない手順**として扱います。

## 2. 指定濫用防止医薬品の数量基準

| ID | 決まり | 内容 | 確認 | メモ |

| Q-1 | 小容量の上限 | 5日分以下。ただし**かぜ薬・解熱鎮痛薬・鼻炎用内服薬は7日分以下** | ☑ | 通知の原文で確認してください。かぜ薬には漢方のかぜ薬も含める（11/5 薬剤師の判断） |
| Q-2 | 大容量 | 小容量の上限を超える包装 | ☑ | |
| Q-3 | 18歳未満 | 大容量は売れない。複数個も売れない（小容量1個まで）。**薬の選択の時点で選べなくし、注意文を表示する** | ☑ | 止める場所は11/4 薬剤師の判断 |
| Q-4 | 18歳以上で大容量・複数個 | 理由と使用目的を確認し、記録する（売れるかは薬剤師が判断） | ☑ | |
| Q-5 | 日数の数え方 | 包装の量 ÷ 1日の最大量（用法どおり） | ☑ | |
