# 症状の分類と効き目の分類の対応（ハッカソン版）

最終更新：2026-11-08
状態：**薬剤師確認済み（11/8・デモ用）**（backlog C-16。Claude の下書きを依頼主＝薬剤師が確認）

薬剤師の確認画面で、薬剤師が患者さんの症状（原文）を見て「症状の分類」を押すと、
下の表で対応する「効き目の分類」（[drugs.md](drugs.md) の取扱薬の列）の薬に印を付け、候補を絞ります。

- 押すのは薬剤師です。AI も仕組みも、症状の文から分類を決めません（決まったこと No.22・ルール10）。
- 印は「薬剤師への提案」です。印が付いても、禁忌の判定はそのまま出し、禁忌の薬は既定で販売する薬に選べません（ルール4）。
- 患者さんの画面には出しません。
- テストにするのは「確認」が ☑ の行だけです。
