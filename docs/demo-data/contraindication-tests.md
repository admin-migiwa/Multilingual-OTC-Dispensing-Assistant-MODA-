## 「店にない商品」のテスト（照合）

照合の段階（11/5 薬剤師の判断）：

1. **まったく同じ成分**：あれば、それだけを候補にする
2. **同じ成分をすべて含む**
3. **同系統の成分構成**（成分の系統の組み合わせが同じ）
4. **同系統の成分を含む**（効き目の分類は問わない）
5. **同じ効き目の分類**

同じ薬は、いちばん上の段階で1回だけ出します。成分の系統は drugs.md の「系統」の列で決めます。**配合剤（成分が2つ以上）**を見せられたときは、薬剤師の画面に「患者さんの主訴（どの症状に使いたいか）を確認する」という印を出します。

## 11/4 に決まったこと（このファイルに関係するもの）

1. 妊娠「しているかもしれない」は禁忌（K26。可能性がある人には販売を避ける）
2. 禁忌に関わる項目で「わからない」と答えたら禁忌にし、その項目が禁忌にならない薬をできるだけ候補に出す（K27〜K30）
3. 出産予定日まで12週より前の妊婦さんの解熱鎮痛薬は注意（K09）
4. 授乳中の C1（鎮咳成分）は禁忌（K18、drugs.md の B・E）

## 11/5 に決まったこと（このファイルに関係するもの）

1. 薬のアレルギー歴が「わからない」は、どの薬でも「アレルギー歴なし」として扱う（K40）。上の 11/4 の2の例外
2. 妊娠「しているかもしれない」は、NSAID系の B・C・D でも禁忌（K43。出産予定日まで12週以内かを聞けないため）
3. F の「長く続けて飲む予定」は14日を超えたら注意（K41・K42）
4. I の飲酒の注意のため、問診 Q11 を I でも聞く（K44）
5. 「店にない商品」の照合の段階を5段階に見直し、配合剤には主訴の確認の印を出す（M01〜M03）
6. 行を確認する内容ごとにまとめた
