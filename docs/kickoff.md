# Code タブで最初に貼る指示

## 準備（1回だけ）

1. Claude デスクトップアプリの Code タブを開き、フォルダに `C:\dev\MODA` を選ぶ
2. 作業するモデルを選ぶ：`/model opus`（または `/model sonnet`）
3. advisor を選ぶ：`/advisor fable`（使えなければ `/advisor opus`）。advisor は作業するモデルと同じか、それより上のモデルにする
4. 完了の判定役は、設定しなければ Haiku になる（設定不要）

## 1回目：仕様の残りを固める（/goal）

次をそのまま貼る。

```
/goal docs/spec.md、docs/design.md、docs/demo-drugs.md、CLAUDE.md を読み、spec.md の「まだ決まっていないこと」のうち「ハッカソンの開発を始める前に決める」と「ビルドの前に決める」の項目を、AskUserQuestion で1問ずつ質問して決め、docs/spec.md を更新するまで続けて。技術選定と画面デザインは聞かない。私が「わからない」と答えたら選択肢を出して。最後に「決まったこと」と「まだ決まっていないこと」を、この会話に一覧で見せて。
```

/goal が終わったら、別のメッセージで「advisor にアウトプットを精査させて」と頼む（/goal の文に入れると、完了の判定役が advisor の精査を見分けられず、/goal が終わらなくなるため）。

## 2回目以降：タスクを1つずつ作る

docs/spec.md の「タスク分解」の ID を入れて貼る（例：T4）。

```
/goal docs/spec.md の T4 を完了する。最後に「できるようになったこと」「確かめ方」「pnpm check の結果」を、この会話に一覧で見せて。他のタスクには手を付けない。
```

並列で進めてよいのは T3・T4・T5・T6 だけ。画面のタスク（T7〜T11）は1つずつ進める。
