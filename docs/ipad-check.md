# iPad の実機で確かめる（T14）

同じ Wi-Fi の iPad から、PC で動かしている MODA を開いて確かめるための手順と、見るところの一覧です。

## なぜ開発サーバー（pnpm dev）だと押しても動かないか

開発サーバーは、安全のため `localhost` 以外（iPad から開く `http://192.168.…` の住所）からの「画面を動かす部品」の読み込みを止めます。
画面の見た目は出ますが、押したときに動く部分（JavaScript）が届かないので、どこを押しても反応しません。

## iPad で開く手順（本番用ビルド。おすすめ）

本番用ビルドには、この止める仕組みがありません。公開先（Render）と同じ動き方なので、通しの確認にも向いています。
PC のターミナルで、リポジトリのフォルダから次を順に実行します。

1. 薬剤師の PIN などの設定（`apps/web/.env.local`）があることを確かめる（なければ `.env.example` を見て作る。中身はコミットしない）
2. ビルドする（2〜3分）

   ```bash
   pnpm build
   ```

3. 起動する（3100 番を使う例。ほかの作業が使っている 3000・3002 番は避ける）

   ```bash
   pnpm --filter @moda/web start -H 0.0.0.0 -p 3100
   ```

4. PC の住所を調べる：PowerShell で `ipconfig` を実行し、「IPv4 アドレス」（`192.168.…`）を見る
5. iPad の Safari で `http://（PC の住所）:3100` を開く
6. 開けないときは、Windows のファイアウォールで Node.js（node.exe）の「プライベート ネットワーク」での通信を許可する（初めて起動したときに出る確認の画面で「許可」を押す）

画面やコードを直したら、`pnpm build` からやり直します（止めるときはターミナルで Ctrl+C）。

### 本物の AI で通すとき

`apps/web/.env.local` に `AI_PROVIDER=anthropic` と `ANTHROPIC_API_KEY=…` があるときだけ、本物の AI（Claude）が動きます。
ないときは「仮の AI（開発用）」で動き、画面にその旨が出ます。デモの台本どおりに通すときは、本物の AI にしてから起動し直します。

### 開発サーバーのまま iPad で開きたいとき

`MODA_DEV_ORIGINS` に PC の住所を入れて起動すると、その住所からの読み込みを許します（ふだんは空）。住所はリポジトリに書きません。

```bash
$env:MODA_DEV_ORIGINS="192.168.x.x"; pnpm dev -H 0.0.0.0
```

## iPad で見るところ（チェックリスト）

デモの台本の流れで、次を確かめます。気になったところは、画面の写真と一緒に Claude に伝えてください。

- [ ] 言語のボタンを押すと、次の画面に進む（押しても動かなければ、上の手順のどこかが違う）
- [ ] 年齢などの数字の欄に触れたとき、数字のキーボードが出て、画面が勝手に拡大されない
- [ ] 文字の欄（症状の入力・翻訳のチャット）に触れたとき、キーボードで欄が隠れない（隠れたら、画面を少し上に動かせるか）
- [ ] 選択肢のボタンをすばやく押しても、画面が拡大されない
- [ ] 右上の小さい「薬剤師用：緊急の確認を開く」を、指で押し間違えずに押せる
- [ ] 「写真で探す」で、iPad の背面のカメラが開き、撮った写真で候補が出る
- [ ] 薬剤師の画面で、薬剤師を選ぶ欄・PIN の欄・禁忌の解除の理由の欄に触れても、画面が拡大されない。PIN は数字のキーボードが出る
- [ ] 説明書の「印刷」で、iPad の印刷の画面（AirPrint）が出て、プレビューに説明書の部分だけが出る（プリンターがなければ、プレビューまでで OK）
- [ ] iPad を縦にしても横にしても、ボタンが切れたり重なったりしない
- [ ] 販売記録の画面（`/pharmacist/records`）が読める

### この方法では確かめられないこと

- **通信が止まったときの緊急案内**：端末に画面を保持する仕組み（Service Worker）は https でしか動きません。PC から http で開く今回の方法では動かないので、公開先（Render の https の住所）で確かめます。
- **ホーム画面に追加**：追加はできますが、いまは Safari のタブと同じ見え方で開きます（全画面にはしていません）。通しの確認は Safari のタブで行ってください。
