## 1. 毎回のタスクの進め方（T3 以降はすべてこの形）

1. **ブランチを確かめる**：Claude に「T4 用のブランチを切って」と頼む（main に直接コミットしないため）。
2. **頼む**：Code タブの入力欄に次を貼る（T4 の部分を変える）。

   ```
   /goal docs/spec.md の T4 を完了する。最後に「できるようになったこと」「確かめ方」「pnpm check の結果」を、この会話に一覧で見せて。他のタスクには手を付けない。
   ```

   ※ /goal の文に「advisor に精査させて」は入れない。自動チェックが advisor の呼び出しを見分けられず、止まらなくなることがある（11/4 に実際に起きた）。精査してほしいときは、goal が終わった後に「advisor に精査させて」と普通に頼む。
3. **待つ**：Claude が質問してきたら答える。「わからない」と答えれば選択肢が出る。
4. **確かめる**：Claude の報告にある「確かめ方」のとおりに、ブラウザ（`pnpm dev` → http://localhost:3000）や iPad で動かす。spec.md の「完了の確かめ方」の欄と同じ結果になればOK。
5. **保存する**：「コミットして、プルリクエストを作って」と頼む。
6. **医療判断にかかわる変更のとき**（`packages/domain`、承認・販売記録・禁忌解除・緊急案内）：別の会話で「このプルリクエストをレビューして」と頼み、指摘を直してからマージする。
7. **止まったとき**：同じエラーが2回続いたら、自分で直そうとせず「何が起きているか、やさしく説明して」と頼む。30分以上かかりそうなら 6章の「削る順番」を見る。
